Rapport du TP n° 2 — Adib OUAMOU

Document principal : TP2_Adib_OUAMOU.tex
Figures : dossier figures/ à conserver à côté du document.

Compilation depuis ce dossier :
  tectonic TP2_Adib_OUAMOU.tex
ou, avec une distribution LaTeX complète :
  pdflatex TP2_Adib_OUAMOU.tex
  pdflatex TP2_Adib_OUAMOU.tex

Overleaf : importer le fichier .tex et le dossier figures/,
puis choisir TP2_Adib_OUAMOU.tex comme document principal.

Le rapport distingue la simulation à poses connues, les transformations
contrôlées de points réels et les recalages d'acquisitions physiques.
Les poses réelles n'ont pas été mesurées : leur incertitude est non quantifiée.
